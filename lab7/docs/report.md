## 1. Предметная область и модель данных

Бытовой планировщик: кому и к какому празднику нужен подарок, что уже куплено и что пора делать срочно. Три базы данных:

- **Люди**: кому дарим подарки.
- **События**: праздники и поводы.
- **Подарки**: конкретные идеи и покупки, связанные с человеком и событием.

Все данные вымышленные, так как страница публикуется в веб.

## 3. Ответ ИИ: схема

### Связи

```
Люди  ◄── Кому ──  Подарки  ── Повод ──►  События
```

| Связь | Откуда | Куда | Зачем |
|---|---|---|---|
| R1 | Подарки.`Кому` | Люди.`Подарки` | видно, какие подарки готовятся каждому человеку |
| R2 | Подарки.`Повод` | События.`Подарки` | видно, какие подарки нужны к каждому празднику |

Обе связи двусторонние (Relation с включённым Show on).

### База «Люди»

| Свойство | Тип |
|---|---|
| Имя | Title |
| Отношение | Select (Семья, Друзья, Коллеги) |
| День рождения | Date |
| Подарки | Relation → Подарки |

### База «События»

| Свойство | Тип |
|---|---|
| Название | Title |
| Тип | Select (День рождения, Новый год, Другое) |
| Дата | Date |
| Подарки | Relation → Подарки |
| Статус | Formula |
| 🎁 Добавить подарок | Button |

### База «Подарки»

| Свойство | Тип |
|---|---|
| Идея | Title |
| Статус | Select (Идея, Куплен, Вручён) |
| Цена | Number |
| Кому | Relation → Люди |
| Повод | Relation → События |

### Формула «Статус» (База «События»)

```
ifs(
  empty(prop("Дата")), "—",
  dateBetween(prop("Дата"), now(), "days") < 0, "⚪ Прошло",
  dateBetween(prop("Дата"), now(), "days") <= 14, "🔥 Скоро",
  "✅ Впереди"
)
```

`ifs` проверяет условия сверху вниз и выбирает первое истинное. Нет даты: прочерк. Дата в прошлом: «Прошло». До события не больше 14 дней: «Скоро». Иначе: «Впереди».

### Кнопка «🎁 Добавить подарок» (База «События»)

Действие: Add page to «Подарки», свойство `Повод = This page`. Создаёт подарок, сразу привязанный к событию, с которого нажата кнопка.

### Представления базы «Подарки»

- Таблица (по умолчанию).
- Канбан: Board, Group by «Статус».
